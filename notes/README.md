# Public Reading Notes

This directory is for notes intentionally shared with the public. Create one file per paper using `TEMPLATE.md`, preferably named `paper-id.md` to match `data/papers.yaml`.

Private annotations—especially user facts, credentials, unpublished work, and personal conversations—should remain in a private vault. A public note may link to the source paper and state your own interpretation; it must not reproduce substantial copyrighted text.
