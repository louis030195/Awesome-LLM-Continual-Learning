# Industry Landscape

This page separates deployable projects and official research releases from the academic paper list. The canonical entries live in [`data/industry.yaml`](../data/industry.yaml), and a generated summary appears in the root README.

## How to read the list

- **Open-source**: inspectable implementation; this label does not imply production maturity.
- **Research release**: artifact accompanying a paper or technical project.
- **Platform/product**: a maintained system or hosted offering; features and terms may change.
- Evidence **B** means the entry is supported by a primary repository, official documentation, or preprint but not independently validated here.

## Evaluation checklist

Before adopting a memory product, test consent, tenant isolation, provenance, conflict handling, deletion, export, observability, latency, cost, and performance on your own longitudinal workload. Prefer reversible memory updates before allowing autonomous parameter updates.

To add or correct an entry, use the repository issue forms and provide a stable first-party URL plus a concrete caveat.
