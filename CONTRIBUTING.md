# Contributing

Contributions are welcome through the issue forms or a pull request.

1. Add papers or industry projects directly to `README.md` and `README.zh-CN.md`.
2. Use stable paper, code, or official project URLs and state caveats plainly.
3. Update a topic page or reading list only when it improves the learning path.
4. Keep private reading comments in your own vault; publish only notes you intend to share under `notes/`.

Keep entries concise, preserve the existing table format, and make the English and Chinese indexes consistent. GitHub Actions checks Markdown links automatically.
