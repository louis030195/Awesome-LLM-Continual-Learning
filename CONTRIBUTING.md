# Contributing

Contributions are welcome through the issue forms or a pull request.

1. Add or update the relevant entry in `data/`.
2. Use stable paper, code, or official project URLs and state caveats plainly.
3. Run `python scripts/validate_data.py` and `python scripts/generate_readme.py --check`.
4. Keep private reading comments in your own vault; publish only notes you intend to share under `notes/`.

Do not edit generated sections between README markers by hand. New topic identifiers must first be added to `data/taxonomy.yaml`.
